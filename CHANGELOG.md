# Changelog

## 1.1.1

- Menu bar icon redrawn to match the other Lightmaster apps (Relief, Overdrive): same stroke weight and size, same spacing in the menu bar.

## 1.1.0

- New: **Capture Previous Area** (⌥⇧P, also in the menu) captures the last selected area
  again, without selecting it. If there is none yet, it starts a normal area capture.
- Installer window: the arrow is now exactly aligned with the icons.

## 1.0.2

- Much lower memory use with many Quick Access thumbnails, and no pause right after a capture.
- Pressing a capture shortcut again cancels the current selection, so a capture can't get stuck.
- History files can only be read and deleted inside the history folder.
- The scrolling capture log no longer stores screenshots in release builds.
- Cleaner installer window, with a centred arrow.

## 1.0.1

- Cleaner installer: the Declic icon, large, on the left and the Applications folder on the right.

## 1.0.0

First public release of Declic, a free and open-source screenshot app for macOS 14+.

- Area, window and full-screen capture, with a magnifier and a window picker.
- Scrolling capture that follows the pane under the pointer, scrolling down or up.
- Video (MP4) and GIF recording of an area, the screen or an app.
- Quick Access thumbnails with copy, save, keep and drag and drop.
- Annotation editor with zoom.
- Capture history.
- Automatic updates from GitHub releases.
- Interface in English, French, Spanish, German and Japanese.
